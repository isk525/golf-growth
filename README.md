# Golf Growth v0.5.3

## 修正内容
- 保存キーを `golf-growth-state` に固定し、アプリ終了・再起動後も実行中ラウンドと履歴を復元
- 旧 `gg-v4` / `gg-v5` データを自動移行
- 実行中ラウンドIDを別途保存し、Firebaseからも復元
- ラウンド終了時、Firestore側にも `status: finished` と終了日時を保存
- 終了済みラウンドに「このラウンドを編集」を追加
- 編集時は終了済み結果を実行中へ戻し、スコアを修正して再保存可能
- テスト・誤登録を端末履歴から削除可能
- 更新通知、ホール選択、Par設定、メンバー履歴、改善提案を維持

注意: 履歴の削除は端末の一覧から除外します。Firestore上の記録は安全のため自動削除しません。
